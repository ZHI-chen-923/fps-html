THE METHOD

透明的换算，可解释的建议

怎么保证数值能输入当前 CS2？

生成值在 sensitivity 的客户端允许范围 0.0001–8 内，保留 4 位小数，直接使用 sensitivity 数值 命令。当前客户端记录的默认 m_yaw / m_pitch 都是 0.022，sensitivity_y_scale 为 1。本工具测量未开镜水平灵敏度；测试使用相同水平/垂直角度增益，因此请使用 m_pitch = m_yaw、sensitivity_y_scale = 1、非反转 Y 的设置。更改过这些参数时先在游戏核对。工具不会自动更改游戏文件。

核对依据：CS2 客户端变量转储（2026-11-10 查询）；Valve Source SDK 鼠标角度计算源码用于解释系数计算，并非 CS2 的完整源码。更新后请用本机控制台查询 sensitivity、m_yaw 复核。

测试结果怎样变成灵敏度？

习惯用于确定搜索起点：手臂/手腕方式和甩过/够不到的问题会小幅调整起点，鼠标垫空间作为转身距离约束。以起点的 0.8、1、1.2 倍形成三个候选（全部限制在游戏范围），实际输入增益随候选变化；不是仅修改界面上的数字。

同一遍的三档使用同一目标序列，第二遍反转候选顺序。甩枪与微调得分 = 每秒命中 × (0.6 + 0.4 × 路径效率) × (0.7 + 0.3 × 完成率)；跟枪得分 = 0.8 × 覆盖率 + 0.2 / (1 + 平均角度误差)。每项先取两遍均值，再除以该项三档最佳得分，按武器需求加权。只有全部完成且每项存在有效表现时才生成建议，不凭空补分。

网页能完全复刻 CS2 / Aimlabs 吗？

这里内嵌的是独立实现的 Aimlabs 风格触碰训练，未接入官方客户端、账号或官方任务。用真实距离校准和透视投影复现未开镜角度增益；投影视场按 CS2 常见的 4:3 基准 90° 垂直视场关系近似，未模拟游戏分辨率拉伸、后坐力或开镜缩放。普通锁定输入的系统加速可能仍造成迁移误差。测试只提供候选建议，应在游戏中复测。

准星、倒计时和中断如何工作？

浏览器会锁定并隐藏系统鼠标，始终绘制中心十字准星。目标接触准星或从其路径穿过即命中，不需鼠标点击。每轮先准备 3 秒，正式时间用 performance.now() 与截止时间计算；Esc、失焦、隐藏页面或长帧中断会作废当前轮，避免把后台时间当作有效表现。恢复后重新开始本轮。

怎么保存与保护数据？

单个 HTML 文件，无第三方脚本、字体、联网接口或统计。设置、校准和测试保存在本机 localStorage；隐私模式、移动文件路径或浏览器清理可能使记录丢失，可导出 JSON 留档。文件无法替你读取 DPI 或控制 CS2。

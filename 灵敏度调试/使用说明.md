# AIM DNA · CS2 灵敏度生成器

用桌面版 Microsoft Edge 或 Google Chrome 直接打开同目录的 **index.html**。不需要安装软件、启动服务器或联网，HTML 文件可单独复制使用。

## 使用顺序

1. 填写鼠标驱动中的实际 DPI、CS2 当前 sensitivity、鼠标垫可用距离与个人习惯。
2. 准备尺子，在鼠标垫标记 10 cm。关闭系统“提高指针精确度”与鼠标加速，进行两次向右直线距离校准，到终点按 Esc。两次差异应不超过 10%。
3. 可以先自由练习。正式测试比较三档灵敏度，每档包含目标转移、精细微调、平滑跟枪，重复两遍，共 18 轮。默认每轮 15 秒，含准备时间约 6 分钟，轮间可休息。
4. 移动鼠标转动视角，让目标碰到中心准星即命中；测试过程不用点击。按 Esc、切出窗口、浏览器长时间中断将作废当前轮，可重新开始，已完成轮次保留。
5. 完成后查看报告，复制 `sensitivity 数值` 到 CS2 开发者控制台回车。保持相同 DPI 与报告中的角度系数。可选下载 `.cfg` 或 JSON 报告。

## CS2 使用条件

- `sensitivity` 输出限制为 `0.0001–8`，保留 4 位小数。
- 默认 `m_yaw = 0.022`。如果修改过，请在游戏控制台输入 `m_yaw` 查询并如实填写。
- 网页测试使用相同的水平、垂直角度增益。对应游戏需 `m_pitch = m_yaw`、`sensitivity_y_scale = 1`，关闭 Y 轴反转。工具只生成 sensitivity 命令，不自动改动这些参数。
- 只比较未开镜灵敏度；不生成开镜倍率。4:3 拉伸、游戏视场、后坐力、实战动作和不同输入处理仍会影响体验。
- 下载 `.cfg` 后放入 CS2 的 `game/csgo/cfg` 目录，在控制台执行 `exec aim-dna-cs2`。只想临时试用时，直接复制报告中的命令即可。
- 当前完整版针对 CS2。其他游戏使用页面“使用与原理”中的自定义 yaw 同距离换算，需自行核实其系数与可输入范围。

## 结果的意义

结果是你完成的三档实际测试中的推荐候选，不是数学上保证唯一的最佳值。报告展示各项成绩、武器对应权重、候选差距和两遍表现波动。候选接近、波动明显或推荐位于边缘时，可在游戏中试用后再次测试。

`cm/360° = 914.4 / (DPI × sensitivity × m_yaw)`。

内嵌任务为独立实现的 **Aimlabs 风格训练**，不是 Aimlabs 官方客户端、官方账号数据或官方任务嵌入。

更换 DPI、浏览器缩放、系统设置、屏幕或窗口环境后应重新校准。设置和成绩保存在当前浏览器的本机存储中；更换浏览器、文件路径、隐私模式或清理缓存可能丢失记录。

已在本机 Edge 浏览器执行自动化验证：真实浏览器鼠标锁定；模拟鼠标移动完成距离校准与全部 18 轮；触碰命中；倒计时递减；中断不入成绩；推荐计算；配置下载；存储恢复；修改 DPI 后清除过期校准；其他游戏换算；移动端无横向溢出。自动化使用模拟移动与虚拟时间验证逻辑，没有代替你的个人测试，也没有在 CS2 客户端内验证实战手感。
